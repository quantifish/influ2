# Native brms implied-effect fixtures

These eight small fits contain genuine, simulated-data MCMC draws generated by
`tools/implied-validation/build-brms-fixtures.R`. Each original fit has four
chains and 4,000 post-warmup draws. The script requires R-hat below 1.02, bulk
ESS above 100, and no divergences before exporting anything. The full fits stay
in ignored `data-raw/brms-implied-full/`.

Each numerical fixture retains 64 evenly spaced joint draws per chain (256
total), with warmup and the platform-specific compiled C++ module removed.
Native `brms::prepare_predictions()` and `brms::log_lik()` are unchanged. The
saved reference likelihood for draws 1 and 17 is checked after serialisation.
Sampling diagnostics in the `implied_fixture` attribute refer to the original
full fit, not the reduced numerical fixture. These are likelihood-adapter
tests, not estimates of posterior uncertainty or scientific calibration.

Models include vessel effects and offsets; the hurdle-lognormal fixture also
has a smooth, observation-specific log-SD, and a separate annual specification
for zero probability. Tests verify encounter orientation, positive-only versus
combined responses, fixed baselines, likelihood shifts, profile endpoints,
row alignment, compact results, unchanged fits/RNG, and explicit limitations.

No Stan compilation or MCMC is run by package tests. The vignette's diagnostic
tables are exported separately from the full posterior by
`tools/implied-validation/export-brms-example.R`.
