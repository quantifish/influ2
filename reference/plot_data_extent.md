# Plot the completeness of variables through time

Plot the completeness of variables through time

## Usage

``` r
plot_data_extent(data, xvar, yvar)
```

## Arguments

- data:

  A data frame.

- xvar:

  Name of the temporal or grouping column.

- yvar:

  Names of columns whose non-missing coverage is displayed.

## Value

A \[ggplot2::ggplot()\] object.
