# Simulated CPUE data

Simulated catch of lobsters per pot from 2000 to 2017, with changing
seasonal, depth, and soak-time coverage. All values are generated by the
deterministic simulator in \`data-raw/compact-brms-fixtures.R\`; no
commercial fishing records are included.

## Usage

``` r
data(lobsters_per_pot)
```

## Format

A data frame with one row per simulated pot lift and five columns:

- lobsters:

  Number of lobsters caught in one pot.

- year:

  Factor identifying fishing year, from 2000 to 2017.

- month:

  Two-digit factor identifying calendar month.

- depth:

  Fishing depth in metres.

- soak:

  Pot soak time in hours.

## Source

Fully synthetic data generated for the package examples.
