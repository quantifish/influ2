# Extract a table from an influence diagnostic

Extract a table from an influence diagnostic

## Usage

``` r
influ_effects(x)

influ_indices(x)

influ_composition(x)

influ_draws(x)

influ_metrics(x)
```

## Arguments

- x:

  An \[influ_diag\] object. \`influ_indices()\` also accepts an
  \[influ_steps\] object and returns its annual step table.

## Value

A data frame.
