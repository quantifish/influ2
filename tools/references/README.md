# Historical reference documents

These PDFs have been moved unchanged from the repository root:

- `Bentleyetal2011Influenceplotsandmetrics.pdf`: the original influence paper.
- `influ_vignette.pdf`: the historical influ vignette.

These are reference documents, not raw observations or package datasets, so
they belong here rather than in `data-raw/`. They retain their original
copyrights; the influ2 MIT licence does not relicense them. Cite the paper
through its DOI in current documentation: <https://doi.org/10.1093/icesjms/fsr174>.

The whole `tools/` directory is excluded from the CRAN source archive. The
installed comparison vignette uses `inst/legacy/influ-proto.R` and the compact
fixtures in `inst/extdata/`, not these PDFs. The frozen Get Started HTML and
its figures remain separately preserved in `pkgdown/assets/articles/`.
